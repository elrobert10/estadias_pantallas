# App de Autoservicio - Cliente en Mesa/Kiosco

Scaffold Vue 3 + Vite + Quasar + Pinia + Vue Router para un flujo táctil tipo kiosco.

## Scripts

```bash
npm install
npm run dev
```

## Flujo

1. Bienvenida
2. Menú y exploración
3. Personalización del platillo
4. Carrito y resumen
5. Checkout y confirmación
