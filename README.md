# Kitchen Display System - Taquería Tradición

Pantalla KDS construida con Vue 3 + Vite + Quasar + Vue Router. Simula la llegada de pedidos a cocina y su avance por estados.

## Scripts

```bash
npm install
npm run dev
```

## Vista principal

1. Tickets nuevos
2. En preparación
3. Listos para pase
4. Historial de pedidos cerrados
